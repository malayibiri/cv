# Projects

A selection of projects I have worked on as lead, analyst or developer. Public source code is available at [github.com/malayibiri](https://github.com/malayibiri) and in the [Tocororo](https://github.com/tocororo) organization.

## Iroko-CRIS and Sceiba

<p class="meta">2022 – present · Project lead, analyst and developer</p>

National platform for monitoring Cuban scientific publications. Sceiba provides a workspace for building information management applications on research output, based on international metadata standards. [Iroko-CRIS](https://github.com/tocororo/iroko-cris) is the current research information system (CRIS) behind the platform.

- Ontology-based data model for metadata interoperability.
- Hybrid retrieval combining the Neo4j graph with full-text search in Typesense.
- FastAPI backend and Angular frontend.

[iroko-cris](https://github.com/tocororo/iroko-cris) · [iroko-cris-ui](https://github.com/tocororo/iroko-cris-ui) · [sceiba-ui](https://github.com/tocororo/sceiba-ui)

## Sceiba Research
